# Misión

Implementad una máquina de estados legible (`ESPERA`, `DESPLAZAMIENTO`, `OBSTACULO`, `INSPECCION`, `PARADA`, etc.) con transiciones basadas en sensores. La lógica de misión no debe importar directamente librerías de GPIO: recibe observaciones del adaptador y emite órdenes limitadas. Registrad cada cambio de estado con fecha/hora y motivo.
