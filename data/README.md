# Datos del proyecto

Guardar solo muestras **pequeñas y necesarias** para repetir una prueba, con licencia/procedencia y división entre ajuste y evaluación. No subir imágenes de personas sin autorización, grabaciones privadas, pesos enormes ni bases de datos con información personal. `data/raw/` está ignorado; documentar en `docs/ia.md` cómo obtener los datos necesarios.
